# Lynia Finance

A modern financial services platform built on Apache Fineract, designed for digital lending and microfinance operations.

## Project Structure

This project is organized into the following main directories:

### 📁 apache-fineract-original/
Contains the original Apache Fineract 1.12.1 source code and all related files:
- Core Fineract modules (accounting, loans, savings, etc.)
- Docker configuration files
- Gradle build files
- Integration tests
- Kubernetes configurations
- Original documentation

### 📁 spec-kit/
Contains Spec Kit framework files for feature planning and specification:
- Memory and constitution files
- PowerShell automation scripts
- Planning and specification templates
- Agent context management tools

### 📁 github-workflows/
Contains GitHub Actions workflows for:
- Gradle build and publish workflows
- CI/CD configurations
- Automated testing pipelines

### 📁 docs/
Contains project documentation:
- Lynia Finance project overview
- Setup guides
- License and contribution guidelines
- Original Apache Fineract documentation
