# Lynia Finance Landing Page

Public website for [lyniafinance.com](https://lyniafinance.com).

This project is organized into four sequential development phases:

| Phase | Directory | Description |
|-------|-----------|-------------|
| 1 | `design/` | Wireframes, mockups, brand assets, and design system |
| 2 | `backend/` | API endpoints, CMS, and server-side logic |
| 3 | `frontend/` | UI implementation, components, and pages |
| 4 | `integration/` | End-to-end wiring, testing, and deployment configuration |

## Getting Started

Work proceeds phase by phase. See each phase directory for detailed instructions.
