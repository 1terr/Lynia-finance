## 4. The Product Bento Grid

### Asset-Backed Lending (Large Card)

- **Headline:** Productive Asset Financing
- **Copy:** We finance the income-generating tools of the informal sector—starting with smartphones and scaling to gig-economy assets.
- **Technical Pillar: IoT-based risk management.** We substitute traditional collateral with real-time asset telemetry. By monitoring usage and health, we enable credit for those the formal system deems "unbankable."
- **CGAP Alignment:** Shifting from "negative collateral" to "productive trust" by funding assets that grow cash flow.

### Digital Credit (Square Card)

- **Headline:** Conversational Liquidity
- **Copy:** Instant, collateral-free credit for civil servants and partner employees.
- **Experience:** WhatsApp-native applications with instant disbursement to **Innbucks**, **EcoCash**, **OneWallet**, or **OMari**.

### Embedded Credit (Wide Card)

- **Headline:** API for Ecosystem Resilience
- **Copy:** Connect via API or data sharing to finance your platform's ecosystem. We analyze mobile money activity to provide credit bundled with health/life insurance and capacity-building mechanisms.

## UI/UX Design Philosophy

### Hero Section

Stripe-style hero with mesh gradient background. The gradient incorporates **Great Zimbabwe zig-zag stone line patterns** inside the gradient — referencing the chevron/herringbone stonework of Great Zimbabwe ruins.

### Statistics Section

Minimalist stat strip inspired by Stripe's "backbone of global commerce" section — large numbers with sources beneath.

### Press / Blog Section

Stripe-style expandable rows on the homepage. Each row shows a logo, headline, and a `+` icon. Clicking expands to reveal the full story excerpt and a "Read the story →" link.

### System Illustration Section

A visual diagram showing the Lynia Finance core engine connecting to:

**Left (Ecosystem Partners):** Retailers, Distributors, Employers, Platforms

**Center (Lynia Core):** KYC Data, Credit Scoring, Loan Disbursement, Insurance

**Right (Mobile Money):** EcoCash, Innbucks, OneWallet, OMari

This illustrates embedded lending — how Lynia orchestrates across mobile money providers, ecosystem APIs, KYC data flows, and loan disbursement.

### Design References

- **Hero gradient:** Stripe.com homepage style with mesh gradient
- **Stats section:** Stripe's "The backbone of global commerce" pattern
- **Blog/Press rows:** Stripe's customer story expandable rows
- **System diagram:** Stripe's "Connect to existing systems" flow diagram
- **Typography:** Inter, weight 500 headings / 300 body (Stripe signature)
- **Color:** Navy #0A2540 + Blurple #635BFF
- **Shadows:** Layered blue-tinted rgba(18, 42, 66, ...) shadows
- **Spacing:** 120px section padding desktop, 1080px max content width
